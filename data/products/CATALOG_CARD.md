# Alibaba.com 商品快照库

## 用途

这份数据是小红书文案生成与事实一致性评测的**商品信息源快照**。它让生成模型先读取同一份
产品资料，再检查输出是否改错商品名、价格、起订量、供应商或卖家原始卖点。

“权威”在本项目中只表示：它是后续实验固定使用的 source of record。它不表示项目方已经
独立验证卖家的材质、认证、功效、销量或库存主张。

## 数据范围

- 采集日期：2026-09-08（页面快照，价格可能随时变化）
- 来源：Alibaba.com 公开搜索结果页，中文页面
- 数量：200 个唯一商品 ID
- 分类：20 类，每类 10 个自然搜索结果
- 广告：排除页面标记为 `Ad` 的付费商品卡片
- 图片：只保存公开图片 URL，不下载或重新分发图片文件
- 描述：`product_name` 与 `selling_points` 来自搜索结果卡片，不是完整商品详情页描述

## 主要字段

| 字段 | 含义 |
|---|---|
| `record_id` | 项目内稳定 ID，格式为 `ali-{product_id}` |
| `product_id` | Alibaba.com 商品 ID，从商品 URL 提取 |
| `product_name` | 页面展示的商品标题 |
| `price_text` | 页面展示的批发价格或价格区间 |
| `min_order_text` | 页面展示的最低起订量 |
| `selling_points` | 商品卡片上的促销或卖家卖点，不视为已验证事实 |
| `supplier_*` | 页面展示的供应商名称、链接与年限/国家信息 |
| `rating_text` / `review_text` | 页面展示的评分与评论数文本 |
| `source_url` / `image_url` | 商品追溯链接与图片链接 |
| `captured_at` | ISO 8601 采集时间 |
| `raw_listing_text` | 商品卡片原文，供审计解析错误 |

JSONL 是原始结构化快照；CSV 是便于人工查看的派生文件，其中 `listing_description` 由
商品标题与卡片卖点拼接而成，不能冒充卖家完整详情描述。

## 生成时的事实边界

1. 价格必须表述为“采集时页面显示”，并保留币种与批发/起订语境。
2. 标题里的“疗愈、抗焦虑、美白、认证、天然”等词都属于卖家来源主张；未经额外证据不得
   改写成确定事实。
3. 不得根据图片 URL、品类或常识补写材质、尺寸、产地、库存、适用人群和效果。
4. 发布真实营销内容前，应回到 `source_url` 复核当前价格、规格和可售状态。

配套 Skill 位于 `skills/xiaohongshu-ins-copy`，会先按商品 ID 调用 `product-brief`，再进入
平台文案流程。
