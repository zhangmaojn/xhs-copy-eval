# Agent 与多模态评测：2 分钟面试卡

## Agent vs 传统 LLM

传统 LLM 评测通常把一次输入输出作为样本；Agent 评测是多轮、带工具和环境状态的轨迹。
同一个任务可能有多条有效路径，结果还受环境版本、工具错误和随机性影响。因此至少看三层：

1. **结果层**：任务成功率、最终状态是否正确、成本和时延。
2. **轨迹层**：计划是否合理、步骤是否冗余、错误后能否恢复。
3. **工具层**：工具选择、参数、调用顺序、权限边界是否正确。

面试一句话：Agent 评测的难点不是“多一个准确率”，而是非确定性的多步交互；要把最终成功、轨迹质量、
工具调用正确性和成本联合评估，并固定环境、允许多次运行。

常见基准（面试前检查最新版本）：SWE-bench（代码修复）、GAIA（通用助理）、BFCL（工具调用）、
τ-bench / τ²-bench（真实领域交互）和 AgentBench（多环境）。

## 多模态

多模态评测除了答案正确性，还要验证图文/音视频证据是否对齐，特别警惕“输入中没有但模型声称看见”的幻觉。
难点包括感知与推理解耦、OCR/空间关系、跨模态证据定位、视频时间理解和数据泄漏。

常见基准：MMMU、MMBench、MathVista、Video-MME。面试时不要只背名字，要能说明它们大致覆盖综合学科、
通用视觉问答、视觉数学推理与长视频理解。
