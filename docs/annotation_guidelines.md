# 标注规范与一致性

## 标注单元

标注员同时查看任务、允许事实、约束和候选文案。参考文案只帮助理解任务，不能按字面相似度打分。
每个维度给 1–5 分，并提供一条可定位到候选文本或缺失要求的证据。

## 核心规则

- 事实忠实：`facts` 未提供的地址、价格、性能、经历和因果关系均视为无依据扩展。
- 个人体验：“我觉得”不能证明普遍性能；客观规格和主观感受必须分开。
- 安全：医疗诊断/治疗建议、绝对功效和结果保证优先判低分，不被文风优势抵消。
- 指令：核心禁用项命中通常不高于 2 分；只遗漏次要标签可为 3–4 分。
- 风格：自然不等于堆 emoji/话题；模板腔、焦虑营销、过度煽动都应扣分。
- 有用性：给出具体步骤、判断边界或可执行信息，而不是只有情绪形容词。

## 双标与仲裁

1. 两名标注员独立打分，不能先讨论。
2. 任一维度差值 ≥2 或通过结论不一致时进入仲裁。
3. 仲裁只依据 Rubric 与证据；若任务本身歧义，标记为数据问题而非强行选边。
4. 先用 20 条试标修订规范，再冻结正式版。

## IAA

- 维度分数为有序变量：优先报告 quadratic weighted Cohen's kappa。
- 多标注员或缺失标注：用 Krippendorff's alpha（ordinal）。
- 同时报告原始一致率和通过/失败一致率，避免单一系数掩盖类别不均衡。
- IAA 低时先检查规范/任务歧义，不要仅通过“培训标注员”解释。
